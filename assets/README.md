# DownloadBot avatar

`downloadbot-avatar.png` — квадратная иконка для Telegram, создана встроенным
инструментом image_gen (навык imagegen). Для установки: BotFather → `/mybots` →
`@votarumdownloadbot` → Edit Bot → Edit Botpic, затем загрузить PNG.

Промпт:

> Use case: logo-brand. Asset type: a square Telegram bot avatar for a video downloader called DownloadBot. Primary request: create one polished original app icon combining the idea of a video play button and a downward download arrow into a single clear mark. Large bold white rounded play-button silhouette with a simple blue downward arrow cut into it, centered on a rich Telegram-blue background with a very subtle soft gradient. Crisp flat vector-like geometry, refined rounded corners, high contrast, friendly and professional. All important forms inside the central 70 percent so a circular crop reads beautifully at 40 pixels. One icon only, full-bleed square 1024x1024, no text, no letters, no watermark, no mockup, no device, no border, no tiny details, no surrounding objects. Keep the arrow and play shape immediately recognizable.
