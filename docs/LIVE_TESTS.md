# Проверка реализации

Дата: **5 ноября 2026, 22:41 МСК**. Проверка выполнена на локальном Windows-хосте:
Python 3.11.1, PostgreSQL 18.6, yt-dlp 2026.10.26 + EJS, Node 24.22.1, FFmpeg 9.0.2.

## Автоматические проверки

**178 passed, 0 skipped**, полный прогон — 40 секунд. Использовалась настоящая
PostgreSQL в отдельной базе `downloadbot_test`; загрузки в обычных тестах заменены
управляемыми адаптерами. Проверены авторизация и изоляция клиентов, аккаунты и cookies,
идемпотентность, конкурентный захват, квоты, retry, lease, отмена, TTL, выдача файлов,
защита сетевого доступа, ограничения загрузки, Telegram-состояние и доставка.

`ruff check src tests scripts`, `compileall`, `pip check` — успешно.
Есть одно предупреждение библиотеки Starlette о будущей замене httpx в TestClient;
оно не влияет на результат текущего прогона. Docker отсутствует на тестовом хосте:
Dockerfile/Compose проверены статически, запуск контейнеров здесь не проверялся.

## Реальные сервисы через HTTP API

Использованы работающие API на localhost:8000, отдельный worker и PostgreSQL.
Скрипт `scripts/live_smoke.py` отправил `POST /v1/jobs`, дождался терминальных
статусов через GET и для успешного задания получил файл через авторизованный
`GET /v1/jobs/{id}/file`. Никаких mock-загрузчиков в этом прогоне не было.

## Что ещё требует внешних данных

- Успешные загрузки YouTube, X, Instagram нужно повторить на хосте, где эти сервисы
  доступны. Поддержка реализована и проверена автотестами, но успешная реальная
  загрузка этих трёх платформ в этой среде **не подтверждена**.
- Пользователь подтвердил отсутствие технических аккаунтов. Импорт, шифрование,
  права использования, передача cookies и ротация проверены синтетическими
  cookies; закрытое реальное видео не проверялось.
- Telegram-токена нет: адаптер и PostgreSQL-состояние проверены автотестами,
  реальный обмен сообщениями с Telegram не выполнялся.

После подключения сети/аккаунтов повторить:

```powershell
python scripts/live_smoke.py --output .runtime/live-smoke.json
python scripts/live_smoke.py --url 'https://www.youtube.com/watch?v=VIDEO_ID' --account-id youtube-team
```

Cookies, ключи, пароль PostgreSQL, реальные видео и тестовые runtime-логи
исключены из Git. Перед коммитом исходники проверены на наличие локальных секретов.
